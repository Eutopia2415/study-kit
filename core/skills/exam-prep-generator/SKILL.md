# Exam Prep Generator

Generate practice that tests real understanding, not keyword recall.

## Workflow

1. Determine exam type, level, and target score when known.
2. Infer weak areas from the provided notes or diagnostics.
3. Build questions across difficulty:
   - Easy recall
   - Medium application
   - Hard trap or transfer
4. Include answer keys with concise explanations.
5. For writing or FRQ-style exams, include scoring criteria and model answers.
6. End with a short weakness diagnosis and next practice step.

## Default Question Mix

When the user does not specify a format:

- 8 multiple-choice questions
- 3 short-answer questions
- 1 challenge case or FRQ-style question
- Answer key and explanations

## Quality Rules

- Distractors should be plausible.
- Test the concept the user is likely to miss.
- Avoid giving away the answer in the wording.
- Mark each question by skill, not just topic.
