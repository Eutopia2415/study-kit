# College Board layout evidence

Research checked 2026-10-06. These are public official sources. Refresh target-year rules when building an assessment, especially an official-format simulation.

## Source observations

- [2026 Calculus AB released FRQs](https://apcentral.collegeboard.org/media/pdf/ap26-frq-calculus-ab.pdf): visually inspected PDF page 10 (question 6). A numbered shared stem precedes a centered bordered value/derivative table. Bold Part A–D labels separate tasks; Roman-numeral subparts appear where needed. Black serif question text, rendered math, generous spacing and simple alignment keep the page readable. The document states that this release is a classroom-optimized rendering of a digitally administered exam; it is not a screenshot of AP Classroom.
- [AP Classroom overview](https://apcentral.collegeboard.org/instructional-resources/ap-classroom): describes Bluebook-style assessments and links the student/teacher guides. The linked student guide returned a dynamic shell through text browsing during this research. No signed-in AP Classroom screen was inspected; do not claim pixel-exact replication.
- [Calculus AB exam description](https://apstudents.collegeboard.org/courses/ap-calculus-ab/assessment): documents hybrid delivery, with digital prompts and handwritten FRQ responses. At the research date, FRQs contribute 50% of the official exam score. The learner's roughly 75% FRQ chapter-practice default is deliberately custom.
- [Official sample response booklet](https://apcentral.collegeboard.org/media/pdf/ap-calculus-ab-hybrid-sample-free-response-booklet.pdf): source for handwriting-space conventions when a printable response booklet is requested.

## Implementing the reference

Use original questions and plain subject titles. Preserve the observed information hierarchy: shared facts first, then labeled parts. Render fractions, roots, primes, piecewise conditions and limits properly. Tables need visible row headings and units. Graphs need labeled axes, enough scale information, exact important points, and clear endpoint conventions. Check mobile/tablet readability and print page breaks; do not split a tiny table or strand a part label at a page boundary.

For browser practice, retain the established Calc navigation and response tools; provide adequate space for handwritten work through photo upload or an optional response sheet. Keep context available beside the response or in an immediately accessible tab. Use common-source stems for related subparts without a tutorial between them. Keep all answers and scoring guidance private during an attempt.

Do not import full-year concepts into a chapter test merely to resemble a released paper. Borrow structure and reasoning demands, not restricted item text or official branding. If the user later asks for an exact AP Classroom UI match, inspect a permitted current screenshot or available signed-in session read-only; clearly identify any remaining approximation.
